## How I work

- **Read first.** Understand the existing code before changing it.
- **Verify.** Run tests, builds, and the app itself before calling something done.
- **Keep it small.** Surgical changes that match the surrounding style.
- **Document briefly.** Short, accurate READMEs beat long stale ones.
